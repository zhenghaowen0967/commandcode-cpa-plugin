批量导入账号 Key

粘贴 JSON 数组或 {"accounts": [...]}。同一真实账号下多个 Key 使用同一个 group_id，max_concurrency 必须相同；已有账号可带 id 更新。

[
  {"name":"账号 A · Key 1","group_id":"real-account-a","api_key":"替换为 Key 1","max_concurrency":4},
  {"name":"账号 A · Key 2","group_id":"real-account-a","api_key":"替换为 Key 2","max_concurrency":4}
]

发送时立即清空输入。遮蔽不受浏览器支持时内容可能可见；请勿在共享屏幕下粘贴。后端可能部分成功，请核对每一条导入结果，不要盲目重复整批。
